# 📝 To-Do List App

A simple, elegant to-do list application built with vanilla JavaScript.

![To-Do App](https://img.shields.io/badge/status-active-success.svg)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow.svg)

## 🌟 Features

- ✅ Add new tasks
- ✅ Mark tasks as complete
- ✅ Delete tasks
- ✅ Filter tasks (All / Active / Completed)
- ✅ Persistent storage using localStorage
- ✅ Clean, responsive design

## 🚀 Live Demo

[View Live Demo](https://s-boldwin.github.io/todo-app/) ✨


## 🛠️ Technologies Used

- **HTML5** - Structure
- **CSS3** - Styling
- **JavaScript (ES6)** - Functionality
- **localStorage API** - Data persistence

## 💻 How to Use

1. Clone this repository:
```bash
   git clone https://github.com/S-Boldwin/todo-app.git
```

2. Open `index.html` in your browser

3. Start managing your tasks!
